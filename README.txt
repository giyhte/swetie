SWEETIE FOX — лаунчер Minecraft 1.21.11 (Fabric)

КАК ПОЛУЧИТЬ .EXE (один раз, бесплатно)
1. Создай репозиторий на github.com и загрузи в него ВСЁ содержимое этой папки
   (вместе с папкой .github).
2. Вкладка Actions -> build-exe -> Run workflow. Через ~3 минуты в Artifacts появится SweetieFox-exe -> SweetieFox.exe.
3. Запусти SweetieFox.exe откуда угодно: он сам покажет установщик, поставится в AppData и
   создаст ярлык «Sweetie Fox» на рабочем столе. (Хочешь без установки — положи рядом файл portable.txt.)

БЕЗ GITHUB (нужен Python 3.10+): двойной клик по SweetieFox.pyw.

ЧТО ДЕЛАЕТ
- Игра/моды не установлены -> кнопка «УСТАНОВИТЬ» скачает всё. Уже есть -> просто «ИГРАТЬ».
- Меню в игре (Right Shift) собирается автоматически (кнопка «УСТАНОВИТЬ МЕНЮ»), лог: tools\build.log
- Все данные лежат рядом с exe (папки game, tools, bundle).
